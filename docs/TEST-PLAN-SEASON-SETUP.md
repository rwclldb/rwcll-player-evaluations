# Test plan: season setup, up to evaluation day

The plan is the spreadsheet **[TEST-PLAN-SEASON-SETUP.xlsx](TEST-PLAN-SEASON-SETUP.xlsx)**: an overview (plan at a glance,
cast and logins, local vs hosted), the step-by-step script with Pass / Fail / Skipped and must-pass steps, read-only
database checks, and a notes sheet.

It is generated by `scripts/build-test-plan-season-setup.py`. Edit the steps there, then rebuild:

```
python scripts/build-test-plan-season-setup.py docs/TEST-PLAN-SEASON-SETUP.xlsx
```

Start state: `npm run fixtures:load -- --reset --bare` (local), or the hosted wipe and `--hosted --confirm-project=<ref> --bare`
load described in the spreadsheet's step 0.1. Expected numbers were checked against the fixture files on 2026-11-11.
